# Learnly — Personal Learning Library Website

Build the full **Learnly** site from the spec in `docs/Personal Learning Library Website Prompt.md` in the currently-empty repo (only `docs/` exists). Scope confirmed: core pages **+ dark mode + localStorage progress tracking + /create JSON generator page**, using **pnpm** and seed data with **real YouTube video IDs**.

## Stack & Tooling
- Next.js (latest, App Router), TypeScript, **no `src/` dir** (matches the spec's structure)
- Tailwind CSS v4 (CSS-token config), shadcn/ui, Geist font (create-next-app default, spec-approved)
- next-themes for dark mode
- pnpm as package manager (enable via corepack if missing)

## Architecture Refinements (beyond the raw spec)
1. **Typed data layer, single source of truth**
   - `data/types.ts` — `Collection`, `Lesson`, `Resource`, `Category` types
   - `data/collections.ts` — seed data only
   - `lib/collections.ts` — all query helpers (getCollectionBySlug, getAdjacentLessons, search, featured, category derivation). Pages stay thin; swapping to a CMS/DB later touches one file.
2. **Durations stored as seconds (number)**, formatted by helpers to "8:20" / "2h 35m" — avoids string parsing, spec display unchanged.
3. **Canonical category list** (`lib/collections.ts`): Academic, Creative, Language, Technology, Health, Finance, Cooking, Music, Lifestyle, Other. The spec has two slightly different lists; unifying them.
4. **Thumbnail fallback chain**: explicit `thumbnail` → `i.ytimg.com/vi/{firstLessonId}/hqdefault.jpg` (configured in `next.config.ts` remotePatterns). Zero image maintenance.
5. **Static generation**: `generateStaticParams` for all collection + lesson pages — fully static, fast, SEO-friendly.
6. **Search/filter/sort is client-side** in one `LibraryBrowser` client component (data set is tiny); initial category read from `?category=` so home-page topic chips deep-link cleanly.
7. **Privacy-enhanced embeds**: `youtube-nocookie.com/embed/{id}?rel=0` in a lazy 16:9 iframe.
8. **Hydration-safe progress**: localStorage read only in `useEffect`, never during SSR.

## Design Tokens (mapped into shadcn CSS variables, light + dark)
- Background `#FAFAFA`, Cards `#FFFFFF`, text `#18181B` / `#71717A`, accent `#6366F1`, border `#E4E4E7`, radius `12–16px` (—radius ~0.875rem). Dark mode: zinc-950/900 equivalents with the same indigo accent. Inter-style clean typography via Geist; lots of whitespace, rounded cards, subtle shadows, minimal animation.

## Implementation Steps
1. **Scaffold**: enable pnpm → `pnpm dlx create-next-app@latest . --ts --tailwind --eslint --app --no-src-dir --import-alias "@/*" --turbopack --use-pnpm` (if the CLI refuses the non-empty dir due to `docs/`, scaffold in a temp subdir and move files in) → `pnpm dlx shadcn@latest init` + add `button card badge input label textarea select sheet separator` → install `next-themes`.
2. **Theme**: map spec palette into `globals.css` tokens, set up ThemeProvider + `theme-toggle.tsx`.
3. **Data layer**: types, seed collections, `lib/collections.ts` helpers, `next.config.ts` image remotePatterns.
4. **Chrome**: Navbar (logo, Home/Library/About, search icon → `/library`, theme toggle, mobile Sheet menu) + Footer.
5. **Home**: Hero (exact spec copy, 2 CTAs), Featured Collections grid, Browse-by-Topic chips, "Made to share what I learn." section.
6. **Library**: title/subtitle, search ("Search anything..."), category chips, sort dropdown (Curated / Title A–Z / Most lessons), responsive card grid (1/2/3 cols).
7. **Collection detail**: cover, meta, lesson count + total duration, Start Learning → first lesson, clickable lesson list with completion styling, Resources section.
8. **Lesson page**: breadcrumb, 16:9 player, title/description/About/Resources, prev–next buttons, right sidebar (desktop) / Sheet drawer (mobile) with current-lesson highlight, "Mark complete" button.
9. **Progress**: `lib/progress.ts` + `use-collection-progress` hook; "3/8 viewed" badges on cards; last-lesson remembered.
10. **About** page (spec copy) + **/create** page: form (collection meta + dynamic lesson rows, "+ Add Lesson"), Publish → generated TS snippet with copy-to-clipboard and download options.
11. **Polish**: `generateMetadata` per page, not-found page, README (run/dev/add-a-collection/deploy), `.gitignore` (from scaffold).
12. **Verify**: `pnpm build` clean, then `pnpm dev` + browser walkthrough of every page (nav, filters, search, video embed, progress, dark mode, mobile width).
13. **Git**: initial commit on `main` once verified.

## Explicitly out of scope (per spec)
No auth, payments, quizzes, LMS features, analytics dashboards, or backend — data lives entirely in `data/collections.ts`.
